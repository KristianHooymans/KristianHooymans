I'm a computer science and pure maths student interested in building things where
mathematics and computer science meet.

I mostly work in **C++** and enjoy understanding systems from first principles,
especially algorithms, low-level implementation, numerical computing and machine learning.

### Currently building

A small **GPT-style language model from scratch in C++**.

I'm implementing the underlying pieces myself rather than using an ML framework:
matrix operations, neural-network layers, backpropagation, attention, optimisation
and training.

The goal is to understand how these models actually work underneath the abstractions.
